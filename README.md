# dsh-settings-groups

**设置管理**：给 DeepSeek Harness 的设置面板侧栏做**分组 + 排序 + 隐藏**，调整设置面板尺寸与位置，提供全部动效一键开关。分组标签做成明确的标题层级，展开收起带过渡，条目像手机图标一样拖着走。

![展开、收起与搜索](docs/nav-collapse.gif)

> 起因：`dsh-settings-nav-organizer` 能折叠分组，但顺序写死（跟着台账 order 走）、组内调不了序、分组行还是跟条目一样高的整行按钮。这个插件只做补不上的那几件事。

## 看看效果

**长按分组标签 → 浮起来 → 经过别处实时让位 → 松手落位**

![拖动分组](docs/nav-drag.gif)

拖动用的是「攥在手里」那套：按住 250ms 浮起（克隆一份跟着指针，原位置淡到 22%），**抓起来的分组会先自动合上**（不带着一整排条目跑），经过别的分组时它们立刻滑开，不是等松手才动；松手后原来的展开状态自动还原。

**管理页：改名字、调顺序、加入分组、看统计**

![管理页](docs/admin-page.gif)

## 功能

| | |
| --- | --- |
| **自由排序** | 分组的先后、组内条目、未分组条目，全都拖得动。核心项和分组共用一条顶层顺序，所以分组能拖到「账号与余额」**上面**。 |
| **分组 / 未分组随意派** | 条目拖到分组标签上就归组，拖到「未分组」就移出。没建分组时导航和原生一模一样。 |
| **隐藏** | 用不上的入口藏起来 —— 导航里彻底不出现，配置留着，「已隐藏」区一键放回。**顶部固定项也能藏**。 |
| **搜索** | 导航顶部一个 30px 的搜索框，细边框 + 细线放大镜，聚焦有灰色荧光圈。输入即过滤，收起的分组里命中的条目也会露出来。隐藏项不参与搜索。 |
| **记住状态** | 哪个分组收着、未分组收没收，全部持久化。关掉 DSH 重启、换窗口、清缓存都还在。 |
| **层级清楚** | 分组标签 **15px 粗体深色**、条目是宿主原本的 14px 常规灰 —— 像 H1 压正文。**组内条目再缩进 30px**，看得出它是谁的下属。细线 chevron（`>` → `v` 转 90° + 放大 15%）。 |

附带：分组新建 / 重命名 / 删除、一键重置、总开关（关掉后导航**完全**恢复原生平铺）、设置面板本身可拖宽 / 可移动 / 可缩放。

**不做**：AI 自动分类、闲置插件清理、插件启停管理 —— 那是别的插件的活儿。

## 安装

本机开发版走 `link:` 接进 profile 的 **bundle 层**（不写宿主 `cordis.patch.yml`，那条通道会被别的插件整文件回写削掉）：

```sh
node scripts/profile.mjs install --profile desktop
node scripts/profile.mjs check   --profile desktop   # 退出码 0 = 接线完整
node scripts/profile.mjs uninstall --profile desktop
```

装完**重启 DSH**（宿主端要加载新插件）。只改 `client.js` 的话，窗口里 `Ctrl+R` 就够。

### 0.1.12：设置管理与动效总开关

入口、管理页标题统一改为「设置管理」，原分组与排序配置继续沿用。页面顶部新增独立的「启用动效」总开关，控制本插件提供的设置开关、功能切换、分组展开收起、搜索与排序补位、菜单、重命名、到达高亮、提示及面板复位过渡。关闭时立即完成正在播放的动效，清理退场画面，拖动和各项设置操作照常可用。

总开关默认开启，偏好同时保存到 localStorage 与宿主配置，刷新、重开和清空缓存后均可恢复；开启动效时仍遵守系统「减少动态效果」。分组功能开关与动效开关相互独立。

### 0.1.11：补齐设置操作动效

- 搜索保持即时筛选，隐藏结果短暂淡出、剩余条目滑动补位；快速输入和清空会清理旧画面，收起分组里的匹配项也能显示。
- 新建分组轻微浮入，下方卡片同步让位；移组、隐藏和恢复会在原位置退场，在目标位置淡入并短暂高亮。拖动松手后也有到达反馈。
- 下拉菜单和删除确认气泡支持关闭淡出及中途重开；退场期间立刻退出鼠标命中和键盘焦点顺序。修复管理页更新时下拉组件被重新创建的问题。
- 重命名时标题与输入框交叉淡入淡出，保存后高亮新标题；成功提示固定位置显示和消失，不再撑动正文，连续操作会重新计时。
- 新增动效跟随系统「减少动态效果」，关闭面板或停用插件会清理退场副本；关闭快照冻结内部动效当时的画面。

### 0.1.10：设置功能平滑切换

左侧功能共用一个持久选中底块，点击时用 280ms 过渡滑到新位置，快速反向点击从当前画面接续。沿用宿主选中色、圆角和原按钮的键盘操作；分组收起、搜索过滤、滚动、主题与侧栏尺寸变化时自动对齐。滑动中关闭设置会冻结底块位置，开启「减少动态效果」时立即切换。

交互参考 [smooth-option-switcher](https://github.com/zhoulinhua0-star/smooth-option-switcher) 的 skill，按 DSH 的纵向导航与不同条目高度独立适配；保留宿主按钮状态，以共享伪元素实现指示器，没有增加运行时依赖。

### 0.1.9：设置关闭同步退场

关闭时改为整块面板同步淡出，约 180ms，无延迟、不缩放文字。快照冻结导航和正文的尺寸、样式、滚动位置及内部动画，清除切页入场标记，避免右侧重播、回顶或重新排版。移动仍连接的面板不会被当成关闭；快速重开立即清除旧快照，开启「减少动态效果」时直接关闭。

### 0.1.8：补位与上下移按钮动画

管理页的固定项、组内条目、未分组条目和分组卡片共用 280ms 平滑补位动画；点击上移 / 下移同样滑到新位置。重排动画在 React 提交后、浏览器绘制前启动，避免先跳到终点再回弹；连续反向点击从当前画面接续，开启「减少动态效果」时直接完成排序。分组按钮每次移动到相邻分组，跳过中间混排的固定项。

### 0.1.7：管理页排序与跟手拖动

顶部固定项与左侧导航共用排序来源，上移 / 下移会跳过中间的分组，立即更新管理页。固定项、组内条目和未分组条目统一使用跟手拖动：鼠标按住移动或长按 250ms 抓起，经过其他行时实时让位；条目可以跨组移动、拖回未分组或拖入已隐藏。触屏可从抓手拖动，普通区域移动仍可滚动。短按释放会取消等待，跨组重建与松手后会清理浮层。

### 0.1.6：大尺寸记忆适配小窗口

设置面板打开时会按当前窗口裁剪记住的宽高、侧栏宽度与位置，避免在小窗口里超出屏幕；面板开着缩小窗口也会自动适配。临时适配不会覆盖原来的尺寸和位置偏好，回到大窗口会恢复原有大小。拖动从当前显示位置开始，较窄窗口下也允许面板缩到原最小尺寸以下。

### 0.1.5：恢复原有设置背景

撤回 0.1.4 的毛玻璃试用效果，设置面板、导航和分组卡片恢复原有背景；保留按钮圆角边框、按列对齐及展开 / 收起动画修复。

### 0.1.3：操作按钮按列对齐

分组标题、组内条目及顶部固定项的图标按钮统一为 28px 方形；分组标题和条目使用相同的右侧留白，让上下各行按钮按列对齐。

### 0.1.2：管理页操作按钮边框

上移、下移、重命名、移出、隐藏及其他操作按钮统一增加 1px 圆角边框，悬浮时边框加深；删除按钮使用淡红色边框，禁用按钮继续淡显。

### 0.1.1：展开 / 收起流畅度修复

- 所有条目先批量读取尺寸，再统一启动动画，取消逐条强制布局与错峰等待。8 条目浏览器场景中，一次点击触发的同步布局从 8～10 次降到 1～2 次（这是启动阶段的布局次数，不代表整段动画帧率）。
- 快速反向点击从当前高度继续，取消旧动画回调，修复标题已展开但条目仍隐藏的问题。
- 动画结束立即清理，行高不再被 flex 二次压缩；支持系统的「减少动态效果」。
- 设置面板关闭时，只在整框退场完成后移除快照，避免内容区的动画事件提前截断画面。

> 装了别的「设置导航」类插件（比如 `dsh-settings-nav-organizer`）要先停掉，两边都会改导航 DOM。本插件检测到旧插件在跑时会**自动退让**，只在管理页挂一条警告。

## 使用

### 导航里

- **长按分组标签 250ms** 浮起，拖动改分组顺序；拖到核心项旁边也能插进去
- 点分组标签 → 展开 / 收起
- 拖条目 → 同样是长按浮起；落到分组标签上归组，落到「未分组」上移出，落到另一条旁边就是排序
- 没建过分组时不注入任何标签，导航跟原生一样

### 管理页（设置 → 设置管理）

- **启用动效**：页面顶部一键开关本插件的全部动效，关闭后立即完成操作；自动记住偏好。
- **新建分组**：输入名字回车
- **分组卡**：整张卡可拖（同一套长按浮起）；右上角图标按钮 `↑ ↓` 调序、`✎` 重命名、垃圾桶删除（**就地弹确认气泡**，不弹系统 confirm；确认后卡片淡出、下面的卡片滑上来填补）
- **组内条目**：拖行调序、`↑ ↓` 精调、`↩` 移出、`⊘` 隐藏
- **顶部固定项**：宿主的官方入口，可以调序、可以藏，但不参与分组（**「设置管理」不在其中** —— 它是本插件自己的页面，算普通条目，想归组就归组）
- **已隐藏**：列出所有藏起来的条目，一键放回；已卸载插件的残留记录也能清掉

## 配置存在哪

**两处，双写。**

| 位置 | 作用 |
| --- | --- |
| `localStorage["dsh.settingsGroups.v1"]` | 同步写入，立即可读；界面渲染先看它 |
| `~/.dsh/dsh-settings-groups.json` | 宿主端落盘（`index.js` 注册 `/api/dsh-settings-groups/config`，只允许回环访问） |

为什么两处：localStorage 按**来源**分，换窗口、清缓存就是另一份，守不住「关了 DSH 再开还是原样」。两份都带 `updatedAt`，启动时比新旧，不会互相覆盖。

### 直接改文件让 AI 帮你配

```json
{
  "_readme": "改完存盘，设置面板开着的话 5 秒内生效。",
  "v": 1,
  "animations": true,
  "groups": [
    { "id": "g1", "name": "模型接入", "entries": ["codex-subscription", "commandcode"], "open": true }
  ],
  "loose": ["memes"],
  "hidden": [],
  "topOrder": ["c:account", "c:general", "g:g1", "c:models"],
  "_labels": { "commandcode": "Command Code", "memes": "表情包" }
}
```

- `groups[].entries` / `loose` / `hidden` 里填 `_labels` 的**键**（那串 id），不是中文名
- `topOrder` 是核心项和分组的混排顺序：`c:` 是核心项，`g:` 是分组
- 手改**不用管 `updatedAt`** —— 靠内容比对，不靠时间戳
- 改完存盘，面板开着 **5 秒内自动跟上**；没反应就点管理页的「从磁盘重载」

## 原理

设置导航不是 Slot，是宿主内部渲染的列表，所以只能：

1. 读 `ctx.slots.entries("settings.section")` 台账拿到所有设置页
2. 把分组标签**注入**导航列表，把原生按钮**移动**（不是复制）成「核心项 → 各分组标签 + 组内条目 → 未分组」的顺序
3. 显隐和动画靠 `data-dsg-*` 属性 + 一段样式表，不动宿主按钮的结构
4. 拖拽用 pointer events 自绘（长按浮起 + 实时让位），**不是** HTML5 拖放
5. `MutationObserver`（带风暴看门狗）跟随宿主重渲染；按钮与台账的映射走「印记 → label → DOM 顺序」三级匹配

停用插件时会把留在宿主按钮上的 `draggable` / `style` / `data-dsg-*` 全部抹掉。

## 几个绕不开的坑（都在代码注释里）

| 现象 | 原因 |
| --- | --- |
| 展开没动画，收起正常 | `display:none` 恢复那一帧浏览器认为元素"刚出生"，`transition` 不启动 —— 两个方向都得用 `@keyframes` |
| 收起留一块空位 | `border-box` 下 `height:0` 被 padding / `min-height` 顶住；内边距跟随高度同步归零，动画期间取消最小高度 |
| 展开收起卡顿、末尾弹一下 | 逐条读写尺寸造成反复同步布局；flex 压缩行高、几何属性的额外 transition 还会干扰动画收尾 |
| 连点后标题与显隐不一致 | 动画过程中跳过了新目标，旧回调又把条目隐藏；反向时必须取消旧回调并从当前画面继续 |
| 关闭面板退到一半突然消失 | 子内容区的 `animationend` 冒泡到整框，误触发快照销毁；必须核对事件来源与动画名 |
| 面板文字发虚 | 常驻 `will-change: transform` 让面板一直待在合成层上，文字失去次像素抗锯齿 |
| 拖完页面不更新 | 导航读 `topOrder`、管理页读 `groups` 数组 —— 两个真相源 |
| 悬浮背景闪 | 按钮自带灰底，压在行的灰底上 |

## 已知边界

- 只处理 `[role="dialog"][aria-modal="true"] > nav > div:last-child` 这个结构，宿主改版可能要跟着调。
- 宿主官方入口靠**白名单**（`general` / `models` / `plugins` / `agent-presets` / `account`）识别，不按 order —— 实测第三方插件也会用 `order 12 / 15 / 25`。DSH 加新内置页时把 id 写进配置的 `coreExtra` 即可，不用改代码。
- 拖拽改顺序后**没有撤销**（写进 JSON 之前可以手动改回来）。
